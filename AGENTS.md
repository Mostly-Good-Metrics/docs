# Agent instructions

This repository contains public customer documentation. Read `README.md`, then
edit the smallest relevant page under `docs/` and keep `sidebars.ts` in sync for
new pages.

Use customer-facing language and document deployed behavior. Backend internals,
admin-only Support MCP procedures, and private runbooks belong in the backend
repository. Portable skill instructions belong in
`Mostly-Good-Metrics/skills`; link to that canonical source rather than
duplicating full skills here.

Run `npm run build` after documentation changes. Do not deploy unless explicitly
requested.
